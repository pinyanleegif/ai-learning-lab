# AI Learning Lab

这是我的 AI 学习实验仓库。

这个仓库不是用来一开始做复杂系统的，而是用来通过一个个小项目，练习和理解 AI 工具的真实用法。

## 学习原则

- 自己动手做
- 项目要小
- 每次只练一个关键能力
- 先跑通，再优化
- 先理解流程，再追求复杂功能

## 这个仓库要练什么

### 1. ChatGPT

练习如何把想法变成清楚的任务说明、项目文档和执行步骤。

### 2. Codex

练习如何让 Codex 读取项目、理解任务、修改文件、生成代码。

### 3. GitHub

练习如何管理项目文件、记录修改历史、查看 commit、使用 README 和任务文档。

### 4. OpenAI API

以后练习如何调用 AI 接口，做一些简单的小工具。

### 5. AI 小项目

通过小项目理解 AI 的实际能力和边界。

## 小项目清单

### Project 01：AI 自我介绍网页

做一个最简单的网页，介绍这个仓库是做什么的。

目标：

- 学会让 Codex 创建文件
- 学会查看 Codex 修改了什么
- 学会提交一次代码修改

### Project 02：AI 学习笔记页面

做一个简单页面，记录我学过的 AI 工具和概念。

目标：

- 学会管理多个文件
- 学会让 Codex 修改已有页面
- 学会用 README 说明项目结构

### Project 03：Prompt 收集器

做一个简单页面，用来保存好用的提示词。

目标：

- 学会做简单表单
- 学会保存和展示文本内容
- 学会把想法变成小工具

### Project 04：AI 问答小页面

做一个最简单的问答界面。

目标：

- 理解前端输入框和按钮
- 理解用户输入和 AI 回复的基本流程
- 为以后学习 API 做准备

## 发给对方的 Agent

不要发文件，也不要复制整份方案。把下面这段话发给对方的 Agent 即可：

```
请阅读这份 GitHub README：https://github.com/pinyanleegif/ai-learning-lab
先用几句话概述这个方案。之后只根据这份 README 回答问题。
README 里没有写的内容，请明确说「README 里没有写」，不要猜测，也不要补充新项目、时间表或实现细节。
```

对方有不清楚的地方，继续问那个 Agent 就行。

## 给阅读本 README 的 Agent

如果你是 Agent，正在阅读这份 README：

1. 先用 3 到 6 句话概述：这个仓库是什么、要练什么、现在做到哪、有哪些硬限制。
2. 只根据本文回答。原文有的，用原文的说法解释。
3. 本文没写的，说「README 里没有写」，不要编造。
4. 不要把这份说明理解成 Cursor Skill，也不需要安装任何技能。

## 给 Codex 的规则

Codex 在处理这个仓库时，请遵守以下规则：

1. 先阅读 README.md。
2. 每次只做一个小项目。
3. 不要一次性加入复杂功能。
4. 不要使用复杂框架。
5. 优先使用简单的 HTML、CSS、JavaScript。
6. 修改后说明改了哪些文件。
7. 不要写入真实个人信息、密码、API Key 或敏感数据。
