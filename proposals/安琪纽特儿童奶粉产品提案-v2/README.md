# 项目背景

出生人口减少，正在改变儿童营养市场的增长逻辑。2025年，全国出生人口792万人，比上年减少162万人，降幅约17%；人口出生率降至5.63‰。对于奶粉企业而言，新生人口减少意味着新增消费者来源收缩，单纯依靠新客自然增长的空间受到挤压，经营重心需要更多转向已有家庭的持续消费，以及不同年龄阶段的营养需求。[（来源：国家统计局）](https://www.stats.gov.cn/sj/zxfb/202601/t20260119_1962330.html)

儿童奶粉面向的消费人群，覆盖多个年龄段，仍有较大的人口基础。2025年，全国在园幼儿3225.52万人，小学在校生约1.02亿人。上述人数不能直接等同于儿童奶粉消费者，但说明学龄前及学龄儿童仍构成一个规模可观的潜在人群。出生人口下降也会逐步传导至这些年龄段，因此，儿童奶粉同样需要面对人口收缩带来的竞争压力。[（来源：教育部《2025年全国教育事业发展统计公报》）](https://www.moe.gov.cn/jyb_sjzl/sjzl_fztjgb/202607/t20260706_1442870.html)

儿童奶粉的市场机会，取决于能否在现有儿童营养消费中获得明确的位置。尼尔森IQ在2025年一季度母婴行业报告中指出，儿童奶粉销量呈现波动，市场已告别过去的稳定增长阶段，同时面临辅食、营养补充品等跨品类竞争。这意味着，儿童奶粉企业既要争取同类品牌的消费者，也要回答家长一个更基础的问题：孩子已有日常饮食和其他营养补充选择，为什么还需要购买这款奶粉？[（来源：尼尔森IQ）](https://nielseniq.cn/global/zh/insights/report/2025/china-quarterly-baby-industry-report/)

与这一竞争格局相对应，儿童奶粉正在呈现围绕细分营养需求开发产品、强化营养补充价值的趋势。尼尔森IQ对报告发布前一年新品的观察显示，“多维营养”概念的综合提及率达到50%，围绕生长发育等需求的产品表达也更加突出。这是新品定位与宣传方向的变化，反映出企业正在通过更具体的营养诉求建立购买理由；它并不等同于消费者购买比例，也不能作为产品功效证明。[（来源：尼尔森IQ）](https://nielseniq.cn/global/zh/insights/report/2025/china-quarterly-baby-industry-report/)

基于上述背景，本项目的机会判断应落在具体需求和产品竞争力上：为哪类儿童提供什么营养价值，凭什么获得家长信任，以及能否以合适的口感、使用方式和价格形成持续购买。只有把这些问题说明白，人口基数才能转化为可争取的消费需求，产品差异才能转化为实际成交与复购。

# 营养强化乳粉的产品价值

儿童奶粉的产品价值，正在从基础乳营养延伸到更有针对性的营养补充。钙、维生素、矿物质与蛋白质构成基础，CBP、乳铁蛋白、酵母β-葡聚糖、DHA、PS、益生菌等特色成分，则成为品牌建立差异、解释产品价值的重要抓手。

对于家庭而言，把这些成分合理加入乳粉，首先带来的是使用上的便利。

多种营养集中补充，减少分别购买和安排的负担。在适宜的配方与食用量下，一次冲调可以同时提供多种营养，减少家长分别准备不同产品、记忆不同食用时间的操作。它的价值是简化补充过程，并不意味着一杯奶就能满足全部营养需求，也不能替代均衡饮食。

融入喝奶习惯，降低坚持的难度。对已经接受奶类、能够正常饮用的儿童而言，营养补充可以与早餐、加餐等固定场景结合，无须另外增加吞咽片剂或胶囊的步骤。相较于零散安排多种产品，这种方式有机会减少遗忘、拒绝食用和中途停止，但实际接受度仍取决于口感、冲调体验与孩子能否持续喝完。

便于按份管理，也更容易解释每日补充价值。明确每份克重、每份营养含量和建议饮用频次后，家长更容易了解孩子每天补充了什么。定量条装还能减少反复量取的操作，方便外出携带和不同照护者交接。产品比较也可以从抽象的“添加多少种”，进一步落实到“每天喝多少、得到多少、花费多少”。

为有依据的营养搭配提供载体。乳粉可以承载经过设计的营养组合，例如钙与维生素D的搭配具有明确的营养学依据，维生素D参与肠道对钙的吸收。但“加入奶粉”本身不能证明所有成分都更易吸收。不同成分的利用情况，还受原料形态、配方比例、加工储存、冲调条件和个体状况影响。因此，产品优势应落实在具体配方上，而不是笼统承诺“吸收更好”。[（依据：美国国立卫生研究院钙营养资料）](https://ods.od.nih.gov/factsheets/Calcium-HealthProfessional/)

# 本案的产品研发方向

这些产品呈现出两个值得关注的共同点。

一是，配方可以覆盖多个方面，购买理由仍需要集中。钙、维生素和矿物质是多款产品共有的基础，真正用于建立产品识别的，往往是CBP、乳铁蛋白、DHA、PS等特色成分，以及品牌围绕这些成分组织的需求表达。例如，蒙牛官网分别将一米八八定位于儿童骨骼成长，将慧聪明定位于学生脑营养，体现了同一企业按需求区分产品的思路。[（来源：蒙牛产品介绍）](https://www.mengniu.com.cn/product/brand/)

二是，相似成分组合已经出现在多个品牌中，单靠堆叠成分不容易形成清晰区别。从现有样本看，钙、赖氨酸和CBP反复组成骨骼成长配方；乳铁蛋白与β-葡聚糖经常共同出现；DHA则与ARA、PS等形成脑营养组合。本案需要进一步明确主要服务哪类儿童、重点回应什么需求，以及每份产品能够提供怎样的营养价值。

据此，本案认为，身高、免疫和脑眼是当前样本中相对集中的三类需求方向，也适合作为后续产品研发与产品线规划的主轴。

身高方向，以骨骼生长所需的营养支持为核心。围绕家长对成长阶段、骨骼发育和日常营养是否充足的关注，研究钙、维生素D及其他适宜成分的组合。产品需要给出清楚的营养依据和每日补充价值，不能将营养支持直接等同于确定的身高增幅。

免疫方向，以日常免疫营养支持为核心。围绕家长对孩子日常体质、入园入学和换季阶段的关注，研究乳铁蛋白、酵母β-葡聚糖等成分的适用性与组合依据。产品定位可以回应这些场景，但“少生病”等市场话术不能直接转化为本产品的效果承诺。

脑眼方向，以学龄阶段的脑与视觉营养支持为核心。围绕学习、阅读和日常用眼场景，研究DHA、胆碱、PS、叶黄素等成分的选择与搭配，明确适用年龄和补充价值，避免将成分添加直接等同于提高成绩、提升智力或改善近视。

后续产品线将沿这三个方向展开，每款产品形成一个明确的主要购买理由，再以基础营养和适宜的辅助成分完善配方。肠道、消化和口感则作为各条产品线共同考虑的使用基础，帮助产品真正进入家庭的日常饮用习惯。三个方向分别规划，上市顺序再结合配方可行性、成本与需求验证确定。

# 三条方向的成分选择与用量推导

三条研发方向均以基础乳营养为底层，通过不同的核心成分组合，形成各自明确的营养侧重。配方开发需要同时回答两个问题：选择哪些成分，以及消费者按照日常饮用方式，实际能够摄入多少。

成分选择首先参考市场中反复出现的组合，再结合适用年龄、营养依据、使用规定、成本及饮用体验确定。添加量则需要区分成品总含量、额外强化量、商品原料投料量和每日摄入量，避免将不同口径的数字直接放在一起比较。

以下市场参考量来自已收集的竞品资料，部分仍待同版标签复核，属于样本范围，不代表全行业统计。研发讨论值参照现有配方方向稿整理，尚不构成最终生产配方。[（参考：三线配方方向稿）](https://docs.google.com/document/d/1T1egb6EMI9jVnAJh_laviMD1pUYH190IYJ4MVdspWvA/edit)

身高方向：以钙、维生素D和CBP为主要研究组合，兼顾其他骨骼营养成分。

现有样本中，这一方向的配方相对集中。钙承担基础营养价值，维生素D与钙搭配，CBP则经常作为特色成分出现在产品表达中。部分产品进一步加入维生素K2、水解蛋黄粉，并突出赖氨酸含量。

| 成分 | 已收集样本中的参考量按每100g粉 | 参考稿中的数值及本阶段处理 |
| :-: | :-: | :-: |
| 钙 | 整体样本约750—1500mg；骨骼成长定位样本多在1050—1500mg | 以成品总钙约1200mg作为讨论起点；实际强化量须扣除乳基料及其他配料带入的钙 |
| 维生素D | 约7.5—8μg | 参考稿列11.2μg，属于按强化上限展开的数值，应与竞品水平分别评估，不直接作为默认目标 |
| 维生素K2 | 约35—45μg | 参考稿列75μg，需结合允许来源、维生素K计量口径及配方需要确定 |
| 初乳碱性蛋白CBP | 约100—200mg | 参考稿列200mg；需先确定每日饮用量，再校核每日摄入及余量 |
| 水解蛋黄粉 | 约20—50mg | 参考稿提出50—100mg，可作为升级配伍的研究范围，比较必要性、成本和口感 |
| 赖氨酸 | 样本标示约1200—1500mg | 先按成品赖氨酸含量研究，不能直接写成额外添加1500mg；应核实乳蛋白贡献、检测方法及允许使用路径 |

钙最能说明口径差异：成品标示1200mg/100g，不代表生产时额外加入1200mg钙。需要先核算乳基料本身的钙，再确定强化部分。GB 14880中的使用量规定与成品标签总含量，也应分别核对。[（依据：GB 14880—2012）](https://www.nhc.gov.cn/ewebeditor/uploadfile/2013/06/20130605103746593.pdf)

CPP、骨胶原蛋白肽、山楂、鸡内金等可保留在备选清单。目前资料不足以给出可靠的儿童奶粉主流定量，暂不为凑齐配方而设定数字。是否纳入，应看其能否提供独立价值，以及是否影响主配方的成本、风味和定位。

# 免疫方向的成分与用量

免疫方向：以乳铁蛋白、酵母β-葡聚糖为核心研究对象，再评估肠道相关配伍。

这一方向的市场组合既包括日常冲饮奶粉，也包括小克重的浓缩营养补充产品。两者可以互相提供成分思路，但添加浓度必须结合每次食用量理解。

| 成分 | 已收集样本中的参考量按每100g粉 | 参考稿中的数值及本阶段处理 |
| :-: | :-: | :-: |
| 乳铁蛋白 | 日常冲饮样本约30—90mg；部分小条装资料标示更高，口径待核 | 参考稿列100mg作为讨论值；需明确是强化使用量还是成品含量，并核对原料规格 |
| 酵母β-葡聚糖 | 大罐样本约20—35mg；部分小条装约40—380mg | 先分别研究日常冲饮和浓缩补充两类方案。参考稿的67mg与500mg来自不同限量推导，不能并列当作同一产品的可选上限 |
| 2′-FL等HMO | 已收集个别样本标示HMO约1300mg，具体组成待核 | 参考稿提出2′-FL约1000mg目标；需按冲调后浓度校核，不能直接将“HMO总量”视为2′-FL量 |
| GOS、FOS | 现有样本尚不足以确定统一主流区间 | 参考稿提出合计约2g，可作为口感、耐受与成本评估的讨论起点 |
| 益生菌 | 样本涉及HN019、BL-99、Bb-12等，活菌数标示口径不完全一致 | 先确定具体菌株，再明确每份及保质期末活菌数；参考稿中的≥10⁶ CFU/g不能直接当作有效剂量依据 |
| 维生素C、锌 | 属于基础营养配伍，样本及原料本底不同 | 参考稿列维生素C 80mg、锌目标约8mg；需进一步区分强化量和成品总含量 |

小条装的浓度高，不一定代表每次摄入更多。例如，某产品若标示乳铁蛋白520mg/100g，每条只有1.5g，则每条折算为7.8mg；另一款奶粉若为100mg/100g，每份25g，则每份为25mg。这一换算只说明份量差异，不能据此判断效果优劣，也不能代替产品类别及标签核验。

HMO还涉及冲调浓度。2′-FL的相关批准规定按即食状态计量，粉状产品需按冲调倍数折算。因此，参考稿中的“约1600mg/100g上限”只有在特定冲调条件下才可能成立，不能作为固定通用值；与其他规定范围内低聚糖合用时，还要校核合计使用量。[（依据：国家卫健委2023年第8号公告附件）](https://www.nhc.gov.cn/wjw/c100175/202310/dd3c911f521d4e9ab855dcb07a2ca76b/files/1734002824452_35039.pdf)

牛初乳、IgG、OPN和接骨木莓相关原料暂列备选，分别核对原料身份、适用范围和配方价值，不能因为竞品宣传中出现，就默认全部纳入。

# 脑眼方向的成分与用量

脑眼方向：以DHA、胆碱和叶黄素建立基础组合，再研究差异化成分。

脑营养与视觉营养可以在同一配方中形成组合，但需要明确主要侧重。DHA、胆碱、叶黄素等已有市场应用基础；PS、唾液酸、MFGM等则需要进一步判断适用路径、用量依据和成本贡献。

| 成分 | 已收集样本中的参考量按每100g粉 | 参考稿中的数值及本阶段处理 |
| :-: | :-: | :-: |
| DHA | 约50—100mg | 参考稿按约100mg展开；需结合成品总脂肪酸量核算，不能视为所有配方都适用的固定上限 |
| ARA | 约60—85mg | 可将样本量级作为研究参考，与DHA共同评估；参考稿仅列比例限值，尚未形成固定目标量 |
| 胆碱 | 有样本约125mg | 参考稿列150mg；应明确强化部分、原料本底与最终标示量 |
| 叶黄素 | 有样本约160μg | 参考稿列270μg；与玉米黄质分别记录，不能把两种成分的数字合并比较 |
| 牛磺酸 | 有样本约30mg | 参考稿列50mg，可与基础配方一起评估，不必只在此方向使用 |
| PS | 有样本约50mg | 保留为差异化候选，准入及原料规格确认后再讨论目标量 |
| 唾液酸／燕窝酸 | 样本资料约25—220mg，包含不同产品形态 | 先核对规范原料名及每份摄入量；参考稿推导的1000mg属于日限折算思路，不应直接升级为配方目标 |

DHA的计算尤其需要准确。按相关标准中“占总脂肪酸比例”的规定，如果每100g成品实际含总脂肪酸20g，0.5%对应100mg；若总脂肪酸为16g，则对应80mg。这里的计算基数是总脂肪酸，不能直接用包装营养表中的脂肪克数替代。[（依据：GB 14880—2012相关使用规定）](https://www.nhc.gov.cn/ewebeditor/uploadfile/2013/06/20130605103746593.pdf)

3′-SL、LNnT、MFGM和核苷酸等先进入候选原料清单。它们各自具有不同的身份和使用条件，也不能仅因与乳营养相关，就统一归入脑眼功效组合。

# 从市场参考量到产品配方

从市场参考量到产品配方，需要完成四步推导。

第一步，统一比较口径。每一种成分同时记录每100g、每份和每日建议食用量，并标明数字属于总含量、添加量还是商品原料投料量。竞品浓度用于比较配方，实际每日摄入用于评估产品的补充价值。

第二步，确定日常食用情景。参考稿暂按每日50g粉测算，这只是研发假设，尚未确定最终条重及饮用频次。在这一假设下，钙1200mg/100g对应每日600mg；CBP 200mg/100g对应每日100mg；乳铁蛋白100mg/100g对应每日50mg；DHA 100mg/100g对应每日50mg。每日粉量一旦改变，全部数字需要同步重算，三款同时或交替饮用的叠加情况也要考虑。

第三步，把营养目标转化为实际投料。以DHA为例，若每100g成品需要由原料提供100mg DHA，而商品原料中DHA含量为10%，理论上需要投入1g该原料，而非100mg。实际生产还需结合原料检测值、乳基料贡献及加工储存损失校核。钙源、维生素预混料和益生菌同样需要按各自规格换算。

第四步，通过样品确定最终目标。对候选量进行营养与适龄评估，并验证口味、溶解性、沉淀、稳定性、耐受和成本。若更高用量不能提供清楚的产品价值，却增加风味、配方或使用负担，就没有必要单纯追求更高数字。

由此，三条方向可以先形成各自的核心成分组合和量级范围，再由工程评估收敛为可生产、可检测、可持续饮用的配方。最终需要交付的，是“每份提供多少、为什么这样配、如何验证”的完整说明。

# 从家长的成长关切，到三条产品方向

前述配方研究回答了产品“可以添加什么、如何确定用量”。进一步形成产品，需要回到家长的购买理由：为什么选择这款奶粉，又希望它为孩子的成长提供什么支持？

围绕本案的研发范围，家长的关切可以归纳为四个具体问题：身体长得怎么样，日常状态好不好，学习探索是否有精神，以及用眼负担是否得到重视。它们分别对应身高、免疫、脑和眼。

其中，脑与眼具有相邻的生活场景：阅读、学习、观察和探索。将二者纳入同一产品方向，有利于形成连贯的沟通主题；配方设计仍需分别明确各自的营养依据。因此，本案将四类关切整合为身高、免疫、脑眼三条研发方向。

## 市场活跃度提供参考，产品主次还要看购买理由

本次研究以儿童营养领域为范围，参考抖音2026年9月的关键词商品及推广样本，实际调用 Jev 进行同尺度评价，得到以下结果：

| 研发方向 | Jev样本营销活跃度评分／100 | 对本案的启示 |
| :-: | :-: | :-: |
| 脑眼 | 79 | 本轮样本中的推广与成交线索较活跃，值得重点研究；仍需判断独立营养品的购买需求能否由奶粉承接 |
| 身高 | 70 | 在儿童奶粉中已有较清晰的产品表达，适合进一步建立具体的购买理由 |
| 免疫 | 67 | 存在乳粉及其他营养补充形态，可作为覆盖日常营养需求的重要方向 |

评分说明：脑与眼分别为75分、83分，按等权合成为79分。以上为有限样本的营销活跃度评价，不代表市场份额、家长关注度或产品效果；70分与67分的差异不足以证明需求存在明确高低。

这组结果说明，三个方向均有可研究的商业活动。其中，脑眼在本轮样本中更活跃，但产品开发的优先级还取决于：家长是否容易理解，需求是否容易被唤起，以及奶粉是否适合承接这一需求。

## 身高，是本案最具直观感知的切入点

从购买沟通角度，本案判断：身高最容易让家长形成具体、可感知的成长关切，适合作为首发主推方向。

这种“体感”首先来自可见、可测量的变化。身高可以留下厘米刻度和成长记录，也会出现在衣物尺码、年度体检等日常场景中。相较于较为抽象的营养概念，家长更容易理解“关注孩子的骨骼生长与日常营养”为什么值得持续投入。

其次，身高具有时间维度。家长关心的不只是某一次测量结果，也包括一段时间内的成长变化。这为产品内容提供了持续沟通的主题：饮食、运动、睡眠与营养共同构成成长管理，奶粉则作为日常膳食中的营养补充参与其中。

再次，身高方向与乳粉的基础营养具有较顺畅的解释关系。可以从蛋白质、钙等基础营养讲起，再说明方向性配方的设计依据，使家长理解产品为什么这样配置，减少单纯罗列成分带来的理解负担。

这里的直观感知，指需求和成长记录更具体，并不意味着饮用后能够迅速感知效果，也不能将自然生长归因于某款奶粉。

基于上述判断，本案建议同步开展身高、脑眼、免疫三条方向的研发，以身高方向建立首发的核心购买理由，脑眼与免疫形成后续产品组合。三条线共享乳粉的基础营养价值，各自突出一个清晰主题，让家长能够按需求理解和选择。

# 从研发方向，到消费者能够记住的名字

研发需要准确，命名需要易懂。面对消费者，产品不宜停留在成分清单和技术分类上，而应形成能够被理解、记住和复述的名称体系。

本案建议采用“系列名＋品名”的两层结构：系列名解释产品关注的成长主题，品名赋予产品形象与情感。

| 研发方向 | 系列名称 | 名称传达的核心印象 |
| :-: | :-: | :-: |
| 身高 | 成长系列奶粉 | 向上生长、积累成长力量 |
| 免疫 | 元气系列奶粉 | 活力、精神与日常好状态 |
| 脑眼 | 灵动系列奶粉 | 好奇、观察、思考与探索 |

“成长、元气、灵动”共同描绘孩子的成长状态，语气积极，也能与不同的视觉形象衔接。其中，成长系列承担首发主推角色；元气、灵动则使产品体系从身体成长延伸到日常状态与学习探索。

在这一结构下，提出三组品名方案。

## 方案一：诗意组——让成长拥有想象力

成长·摘星 ｜ 元气·追光 ｜ 灵动·揽月

这一组以星、光、月构成统一的意象，用“摘、追、揽”三个动作，让名称具有主动探索的生命力。

| 名称 | 命名构思 |
| :-: | :-: |
| 成长·摘星 | “摘星”带有向上伸展、不断接近目标的画面，与成长主题自然衔接，传达对孩子成长的期待 |
| 元气·追光 | “追光”强调向前、活力与行动，适合表现孩子积极参与日常生活的状态 |
| 灵动·揽月 | “揽月”承接好奇心与想象力，将观察和探索延伸到更广阔的世界 |

这组名称的优势是画面感强，三款之间有共同的故事空间。包装、插画和内容可以围绕星光、天空与探索展开，形成完整的系列识别。

它更适合突出情感价值与视觉表达。具体产品差异则由“成长、元气、灵动”及配方说明承担，避免三个诗意名称美则美矣，却让消费者分不清产品。

## 方案二：琪字组——把品牌联系写进品名

成长·琪帆 ｜ 元气·琪烁 ｜ 灵动·琪澄

这一组以“琪”为共同字根，与“安琪纽特”形成文字上的品牌呼应；通过第二个字区分三条方向，建立统一而可延展的产品家族。

| 名称 | 命名构思 |
| :-: | :-: |
| 成长·琪帆 | “帆”代表启程与前行，以扬帆的形象表达成长过程中的积累和进步 |
| 元气·琪烁 | “烁”代表闪亮与光彩，呼应元气系列的活力感和明亮状态 |
| 灵动·琪澄 | “澄”代表清澈与澄明，呼应观察、思考与探索的系列意象 |

这组名称的优势是品牌关联明确，适合长期积累系列资产。“琪”提供共同识别，“帆、烁、澄”提供区分，后续扩展产品时也有相对稳定的命名规则。

这一联系属于命名设计意图，能否被消费者自然识别，仍需通过实际包装呈现与测名验证。

## 方案三：叠字组——让产品像孩子熟悉的小伙伴

成长·昂昂 ｜ 元气·沛沛 ｜ 灵动·澄澄

这一组以叠字形成亲切、可爱的昵称感，使产品更容易与儿童形象、角色和日常交流结合。

| 名称 | 命名构思 |
| :-: | :-: |
| 成长·昂昂 | “昂”有昂首、向上的意味，叠读后保留积极感，同时增加童趣 |
| 元气·沛沛 | 取“充沛”之意，突出饱满、有活力的形象，与元气主题贴合 |
| 灵动·澄澄 | 取清澈、澄明之意，形成温和、清亮的角色印象，与灵动主题衔接 |

这组名称的优势是亲近儿童，便于角色化表达。家长说得顺，孩子也容易将其当作一个熟悉的称呼。若后续以卡通形象、条装包装或亲子互动内容作为主要表达方式，叠字组具有较好的延展空间。

## 三组名称的共同逻辑

三组方案均遵循“先说明方向，再建立记忆”的原则。

在结构上，采用前项限定、后项识别的偏正思路。“成长、元气、灵动”先限定产品主题，后面的专名承担识别与记忆功能。这里的偏正思路指完整名称的信息关系；“摘星、追光、揽月”三个词本身则是动宾结构，动作感正是其表现力来源。

在读音上，兼顾响亮、节奏和区分度。“昂、帆、光”等字具有较舒展的听感；“烁、澄、沛”通过不同声韵形成区分。开口感是部分名称的表达优势，不必要求所有名字都采用同一类发音，更重要的是完整名称顺口、容易听清、不易混淆。

在品牌与情感上，三组各有侧重：诗意组重想象，琪字组重品牌，叠字组重亲近。它们分别对应三种不同的产品表达选择，而不是九个孤立的名字。

最终选择应同时考虑品牌授权、商标可用性、消费者理解和包装表现。以上名称均为候选；系列名与品名用于建立产品识别，具体营养作用仍由最终配方、标签与经审核的产品说明清楚表达。

评分来源：儿童营养三主题比较与Jev评分，2026年10月6日；研究底稿见本项目“研究成果/20261006_儿童营养三主题比较”。

# 三条系列的基础色与统一应用规则

三条系列的数字设计色已确定：成长采用杏橙，元气采用青碧，灵动采用月光蓝紫。三者形成由暖到冷的色彩关系，并通过共同的奶白底色、深靛文字和少量柠檬黄点缀，建立统一的产品家族识别。

| 系列 | 系列主色 | 条装底色 | 色彩角色 |
| :-: | :-: | :-: | :-: |
| 成长 | 杏橙 #F5862E | 浅杏 #F9DABE | 温暖、向上、有活力 |
| 元气 | 青碧 #13A89E | 浅碧 #B9E0D8 | 清爽、有精神，衔接暖冷两端 |
| 灵动 | 月光蓝紫 #8A91D5 | 浅月光 #CDCEE4 | 安静、清亮，兼顾好奇与探索 |

比例统一，应用有弹性。外盒正面以奶白 #FAF6EE 约60%、系列色约30%、深靛 #1F2A44 约10%作为大致视觉关系，深靛主要承担文字与信息表达，不为凑比例额外增加深色块。柠檬黄 #FFD23F 仅作少量点缀，从整体配色中调剂，平涂、不加光晕。条装沿用各系列的浅色底与识别色，比例单独安排。

文字统一，保证信息层级。三条系列色带均采用深靛文字，不使用白字。色带优先放大字和简短信息，详细说明放在奶白区域；缩略图可读性仍需结合字号、字重、排版和图片压缩进行检查。

按所定HEX色号计算，深靛文字与杏橙、青碧、月光蓝紫的屏幕对比度分别约为5.66∶1、4.84∶1、4.81∶1；白字则分别约为2.52∶1、2.95∶1、2.96∶1。深靛组合均超过网页普通文字常用的4.5∶1参考线，但该指标仅辅助屏幕可读性判断，不能代替包装印刷与实物检查。

对比度参考：[W3C WCAG 2.2 文字最低对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

识别统一，差异不只靠颜色。包装以系列名、品名、IP形象及色带共同区分产品。与安琪既有产品的色彩差异用于强化识别、减少混淆；渠道差异还需由配方、规格、价格和销售条件共同支持。

锁定数字色，印刷以校样为准。HEX用于数字设计与屏幕沟通，纸盒和条袋应结合实际材质、油墨与表面工艺进行打样，形成可执行的印刷配色及验收样。三款并排检查视觉轻重、文字清晰度和系列区分，避免仅凭屏幕色卡判断成品。

三条线均不使用金色、烫金和向上延伸的渐变。系列色采用平涂表达；荧光色及各系列的具体禁用色见下页色彩说明。

# 成长系列 杏橙

成长系列主色为杏橙 #F5862E，条装底色为浅杏 #F9DABE。它承担三条系列中的暖色角色，用温暖、明亮的视觉印象呼应成长主题。

颜色理念。杏橙取意早晨阳光的暖橙感，希望唤起温暖、食欲与活力的联想，为成长系列建立亲切、积极的第一印象。这属于视觉表达意图，不作为促进食欲或生长效果的承诺。

包装应用。外盒以奶白为主要底色，杏橙用于系列色带和关键识别区域，深靛承担文字。柠檬黄仅作小面积点缀，采用平涂，不加光晕。色带上的大字与简短信息统一使用深靛，详细内容安排在奶白区域。

条装衔接。采用浅杏打底，通过杏橙识别元素、系列名和统一字体，与外盒形成一套视觉关系。条装不机械照搬外盒的60／30／10比例，重点保证拿出外盒后仍能识别为成长系列。

使用边界。不使用金色、烫金、荧光橙和向上延伸的渐变，避免过强的刺激感或金属感。杏橙底不用白字。

# 元气系列 青碧

元气系列主色为青碧 #13A89E，条装底色为浅碧 #B9E0D8。青碧在杏橙与月光蓝紫之间形成过渡，以清爽、安静而有活力的气质表达日常好状态。

颜色理念。青碧是略带绿色的清透青色，取意早晨湖水与初生新叶，传递干净、有精神的视觉印象。整体保留活力，但不采用运动饮料式的高刺激亮绿。

产品识别。选择青碧而非更偏蓝的湖青，意在强化与安琪既有小蓝罐的视觉区分，减少消费者混淆，为定制产品建立独立识别。是否足够区分，仍需在完整包装及实物并排对比中确认；颜色本身不能保证避免渠道比价。

包装应用。外盒沿用奶白约60%、青碧约30%、深靛约10%的视觉关系。青碧色块上的文字使用深靛，不使用白字；柠檬黄只作很小的平涂点缀，不加光晕。

条装衔接。浅碧作为条装底色，通过青碧色带与系列信息连接外盒，使内外包装保留同一套识别。

使用边界。不使用金色、烫金、荧光绿和向上延伸的渐变。通过留白、清晰的信息层级与克制的图形，保持清爽、安静、有活力的整体气质。

# 灵动系列 月光蓝紫

灵动系列主色为月光蓝紫 #8A91D5，条装底色为浅月光 #CDCEE4。它承担三条系列中的冷色角色，表达安静、清亮的气质，与“揽月”“澄”等候选名称的意象衔接。

颜色理念。月光蓝紫偏冷而不过分刺激，设计目标是与杏橙、青碧保持协调的视觉轻重。三款是否均衡，以相同版式的并排包装样稿和实物校样确认，不将不同色相直接视为同等明度。

湖水意象与儿童感。湖水感由IP身上的水滴、涟漪和月光等辅助元素表达，无需依赖底色变成湖蓝。IP应以观察、探索、有反应的动作和表情补足活力，避免色彩与形象同时过于安静，使整体偏向成人护理或助眠产品的观感。

包装应用。外盒沿用奶白约60%、系列色约30%、深靛约10%的视觉关系。月光蓝紫色带统一使用深靛字，不使用白字；柠檬黄只作少量平涂点缀。条装用浅月光打底，与外盒保持系列关联。

既有产品对照。前期已对安琪小蓝罐及乳铁蛋白粉蓝袋的京东图片做过初步取色比较，该比较仅作为设计参考，不能代替实物色差测量或消费者识别测试。正文不采用尚未明确算法与取样条件的色差数值，最终以完整包装和实物并排对照为准。

性别观感与使用边界。以偏中性的观感为设计目标，男孩家长的接受度待家长测试确认。不使用金色、烫金、深紫、荧光蓝及向上延伸的渐变。

## 产品规格

本案产品规格设计为：

700g/盒＝25g/小包×28小包。

以700g作为整盒比较基准，便于与市场上的同规格儿童奶粉对照；以25g独立小包作为使用单元，便于定量冲调、携带和分次取用。

对消费者的价格表达同时保留三个维度：

每盒价格：判断一次购买的支出。

每100g价格：与不同规格的竞品比较。

每小包价格：理解一次取用的成本。

每包价格为整盒价格的折算值，不代表独立零售价格；每日饮用包数另按最终配方与食用建议确定。

## 定价原则

本案将成交价下的交付口径毛利率不低于70%作为价格设计底线，采用不低于完整交付成本3.5倍的定倍率定价法。

这里的成本按每盒产品计算，包括：

料体＋内外包装＋仓储及出库作业＋发货物流＋样品分摊。

样品成本应按预计承担的样品用量及相关交付费用，分摊到对应销售盒数中，不能只核算正装出厂价。成本目标控制在45—70元/盒，各款产品分别核算，不以三款平均成本替代单款成本。

计算关系为：

交付口径毛利率＝（实际成交价－完整交付成本）÷实际成交价

成交价＝成本×3.5时，交付口径毛利率约为71.43%。

因此，3.5倍定倍率能够覆盖“不低于70%”的设计要求，并留出少量计算余量。该毛利尚未扣除达人佣金、平台费用、广告投放、税费及固定运营费用，也不代表经营净利润；退货售后等支出需在后续经营模型中计入。

## 测算口径与基础参数

投产 ROI＝广告归因收入 ÷ 对应广告费。

ROI 2.5 表示投放 100 元，形成 250 元广告归因收入。本轮收入按退款前支付金额计算，退款另扣。

共同投流时，先合并同一项目双方的广告费计算 ROI，再分担费用。仅将广告费转给达人，会提高我方表面上的收入与广告费之比，却不代表广告效率改善。后台净成交等指标需先核对定义，不能直接代入本模型。来源：[巨量千川官方指标资料](https://open.oceanengine.com/labels/12/docs/1871505298758800)。

| 参数 | 本轮采用值 |
| :-: | :-: |
| 产品与成交价 | 三款均为 700g，统一按 199 元／盒测算 |
| 完整交付成本 | 每款先按 55 元／盒，包括料体、包装、仓储、发货和样品分摊 |
| 初期投产 ROI | 2.5，作为预算基准，不是保证能够达到的下限 |
| 公司直播间主播提成 | 5%—10% |
| 达人自行直播、自行投流 | 佣金最高 40% |
| 佣金计提基础 | 退款后的有效成交收入；退款对应佣金不结算或追回 |
| 月固定费用 | 客服、文案工资 10,000 元＋AIGC 成本 10,000 元 |

退款和费用沿用前期预算框架：发货前退款 5%、发货后退款 5%，均以支付订单为分母；平台及支付费预留退款后收入的 5%，间接税预算预留 6%。这些是测算参数，不是已核实的实际费率。

退款不返手续费暂按退款金额的 0.6%预留，逆向处理按每个发货后退款订单 6 元计；额外损耗暂按已发货交付成本的 1%预留，退货商品回收收益按 0 计。样品已包含在交付成本中，AIGC 已包含在固定费用中，不重复计入。

以下默认一单一盒。三款销量相加计算总订单量，但各款成本分别核算。除特别说明外，不预设广告归因范围之外的额外成交。

## 投流承担与合作提成

以下统一使用 ROI 2.5、199 元成交、55 元交付成本，暂不预设广告归因范围外的额外成交。投流承担越多，佣金就应相应降低。

| 合作方式 | 我方承担广告费 | 主播／达人提成 | 我方每单贡献 | 月保本支付量 |
| :-: | :-: | :-: | :-: | :-: |
| 公司直播间，起步条件 | 100% | 10% | 8.70 元 | 2,300 单 |
| 公司直播间，较优条件 | 100% | 5% | 17.65 元 | 1,134 单 |
| 达人直播，我方全部投流 | 100% | 15% | −0.26 元 | 放量无法保本 |
| 双方共同投流 | 75% | 15% | 19.64 元 | 1,019 单 |
| 双方各承担一半广告费 | 50% | 25% | 21.63 元 | 925 单 |
| 达人承担大部分广告费 | 25% | 35% | 23.62 元 | 847 单 |
| 达人自行直播、自行投流 | 0% | 40% | 34.57 元 | 579 单 |

最后一列为各模式单独承担全部固定费用时的比较。实际混合经营，应将各渠道订单贡献相加后，统一扣除 2 万元固定费用，不能重复分摊。

合作条件还必须检验达人一方的收益：

| 合作组合 | 达人每单佣金扣除其广告费后的余额 |
| :-: | :-: |
| 我方投 75%、达人提成 15% | 6.97 元 |
| 双方各投 50%、达人提成 25% | 4.98 元 |
| 我方投 25%、达人提成 35% | 2.99 元 |
| 达人自投、提成 40% | −7.96 元 |

上述余额尚未扣除达人自己的主播、人员、场地和税费。40%是可提供的佣金上限，不代表达人在 ROI 2.5 下愿意长期合作。扣除 10%退款后，达人每单收到佣金 71.64 元，而广告费为 79.60 元。

在全部成交均为广告归因收入的假设下，达人拿 40%佣金，ROI 至少约 2.78才仅够支付广告费；ROI 为 3.0时，每单剩 5.31 元覆盖其自身费用；ROI 为 3.5时，每单剩 14.78 元。

因此，后续不能将所有渠道的佣金一并压至 5%—10%。公司直播间可采用低提成，承担全部投流的达人则需要保留足够的获客空间。

## 经营效率改善与收益目标

仍按公司直播间、全部由我方投流测算。下表每格为“每单贡献／月保本支付订单量”。

| 投产 ROI | 主播提成 10% | 主播提成 7.5% | 主播提成 5% |
| :-: | :-: | :-: | :-: |
| 2.5 | 8.70 元／2,300 单 | 13.17 元／1,519 单 | 17.65 元／1,134 单 |
| 2.8 | 17.23 元／1,162 单 | 21.70 元／922 单 | 26.18 元／764 单 |
| 3.0 | 21.96 元／911 单 | 26.44 元／757 单 | 30.92 元／647 单 |
| 3.5 | 31.44 元／637 单 | 35.92 元／557 单 | 40.39 元／496 单 |

据此可划分三个经营状态：

起步保本： ROI 2.5、提成 10%，月支付约 2,300 单。

形成合理收益： ROI 3.0、提成 7.5%，月支付约 2,345 单时，经营结余率可达到退款后收入的约 10%。

具备较好扩量空间： ROI 3.5、提成 5%，每单贡献约 40.39 元，固定费用对经营的压力明显下降。

流量增长不会自动降低佣金。提成下降需要来自提前约定的阶梯条件、重新协商，或低佣公司自播在整体销售中的占比提高。不能将尚未谈妥的降佣计为确定利润。

## 自然成交与经营控制

自然流量增加可以减少同等销售规模所需的广告费，但必须与广告归因收入去重。

例如第六个月仍销售 4,000 单、ROI 3.5、提成 5%，如果其中 20%成交确实来自广告归因范围之外，其余条件不变，月广告费可由约 22.74 万元降至 18.19 万元，月经营结余相应增加约 4.55 万元。

如果这部分收入已包含在后台广告归因收入中，就不能再增加一次自然流量收益。复购也需要扣除其实际广告、佣金和交付费用，不预先将复购收入当作免费收益。

经营过程中关注三项判断：

成熟订单贡献。 广告、佣金、退款等扣完后，每单贡献必须为正，否则销售越多亏损越大。按本轮基准，ROI 降至 2.0、提成仍为 10%时，每单贡献约为 −11.20 元。退款与佣金应在同批订单成熟后核算。

新增投放收益。 扩量后确认新增订单仍有贡献，不能仅凭历史平均 ROI 决定加预算。广告归因收入、广告费与订单范围需保持一致。

现金周转。 保本基准月需要约 18.31 万元广告消耗，还涉及库存、发货及结算等待。利润表保本不代表只准备 2 万元即可启动。首批库存、一次性启动支出及周转资金需另行核算。

测算依据：本轮确认的三款同价、佣金区间和月固定费用；前期提案退款与费用预算框架；本项目 2026 年 10 月 5 日成交渠道研究。以上模型随实际交付报价、合作合同、结算费率及成熟订单数据更新。

新品阶段测算说明。本项目处于新品开发与上市准备阶段，当前经营测算采用偏保守的启动预算假设，暂不计入未经验证的自然成交和复购收益，主要用于判断保本条件与经营空间。上述三款同价、199 元成交价及投产 ROI 等均为阶段性测算设定；实际首发选品、价格体系和可持续投产 ROI，仍需结合产品报价、渠道反馈及试投结果进一步讨论确定。半年改善表为条件情景，不作为业绩承诺，实际结果也可能低于本次测算。

# 品牌传播与内容建设

新品进入市场，首先需要回答家长三个问题：凭什么相信这款产品，它与自家孩子的日常有什么关系，实际使用体验如何。本案将这些问题归纳为客观、主观、直观三类内容，分别承担事实说明、价值表达和体验呈现的任务。

客观让家长信得过，主观让家长用得上，直观让家长愿意说出去。

三层是并列的内容类型，并非消费者必须依次经过的购买阶段。一张商品详情页、一场直播或一条短视频，可以同时使用三层内容，但每项表达的身份与依据必须清楚。

| 内容层次 | 回答的问题 | 主要内容 | 成立条件 |
| :-: | :-: | :-: | :-: |
| 客观 | 这是什么，依据在哪里 | 产品类别、配料、含量、规格、生产信息及使用说明 | 有可追溯的资料，能够核对 |
| 主观 | 为什么值得我考虑，怎样融入日常 | 产品定位、选择理由、生活场景、品牌形象 | 建立在事实之上，不超出证据范围 |
| 直观 | 实际用起来怎么样 | 真实开盒、冲调、饮用过程及家长反馈 | 来源真实、取得授权、保留原意 |

三层之间建立明确的约束关系：客观事实约束品牌主张；真实反馈检验品牌主张与实际体验是否一致；口碑不能替代成分检测或改写事实。如果反馈暴露出事实资料可能有误，应回到标签、检测和生产记录复核，依据复核结果修正。

品牌广告、情景演绎和真实用户反馈分别标识，不借用户之口表达品牌本身不能成立的主张。

## 客观层的产品事实卡

对新品而言，信任首先来自产品信息清楚、前后一致、查得到依据。客观层不堆砌专业名词，而是让家长能够看懂并比较。

三条产品线分别建立事实卡，统一包含：

产品身份： 最终食品类别、适用年龄、规格及生产信息。按最终标签说明调制乳粉的定位，以及与婴幼儿配方乳粉等类别的区别，避免把不同产品混作同一标准比较。

配方事实： 主打成分、含量、单位和信息来源。主要比较口径统一为每100g；必要时辅助呈现每25g小包的对应含量，明确两者关系。

使用信息： 冲调方式、建议用量、储存方法及相关提示，以最终标签和确认资料为准。

品牌与生产依据： 经核实的品牌授权、生产企业和相关资质。配方由安琪专业团队评估确定的合作安排，与已经完成的研发成果分别表述。

配方未定时，内部事实卡保留“待工程师确认”；对外内容只使用已经确认的部分。研发目标、原料添加量与成品含量分别记录，不能相互替代。

事实卡采用“缩略版＋完整版”：缩略版在240px宽度下，仍能辨认产品线、主打成分及其含量单位；完整配料、营养信息和来源放在详情版中。可读性依靠信息取舍，不靠把所有内容压成小字。

同步制作“调制乳粉怎么看配料表”“每100g与每小包怎样换算”“三款产品有哪些已确认的区别”等内容，为直播讲解、商品详情和客服答疑提供统一依据。

## 主观层的选择理由与生活场景

事实卡解决“产品有什么”，品牌表达进一步说明“为什么值得考虑、怎样使用”。本案以孩子的日常生活作为沟通入口，让产品进入家庭能够理解的具体情境。

场景用于解释使用方式，产品之间的选择依据仍应来自最终配方、适用条件、口味、规格和价格。不能仅凭“爱运动”“换季出门”或“喜欢搭积木”，判断孩子需要哪一款。

三条线可按以下方向组织内容：

| 产品线 | 场景入口 | 内容重点 | 表达边界 |
| :-: | :-: | :-: | :-: |
| 成长系列 | 早餐准备、户外活动回家后的家庭日常 | 经确认的主打成分、条装取用和冲调过程；以杏橙表达温暖、活力 | 不承诺长高，不以身高尺、前后对比暗示增高结果 |
| 元气系列 | 出门前准备、周末出游、换季时的生活安排 | 已确认的配方差异、日常饮用安排和携带体验；以青碧表达清爽、有精神的品牌气质 | 不把换季场景连接到少生病、不请假或增强抵抗力的结果 |
| 灵动系列 | 亲子搭积木、桌面手工的下午 | 经确认的成分信息与家庭陪伴场景；以月光蓝紫、涟漪和月光元素形成识别 | 不讲学习、思考或喝后更专注，不出现眼睛画面及视力改善暗示 |

三条线共用“场景—问题—产品信息—喝法”的内容结构，其中“问题”优先选择家长真实面对的使用问题，例如怎样比较配料、如何定量取用、外出怎样携带，而不是制造身高、疾病或学习焦虑。

例如，一条品牌演绎短片可以从“周末出门，家长怎样准备孩子的随身物品”切入，展示条装收纳和按标签冲调的过程。它表达的是使用便利，不将出游、运动或孩子的状态归因于饮用产品。

品名、颜色、星星月亮和IP是品牌识别与情感表达的一部分，帮助家长记住、区分产品；它们属于主观表达，不构成产品效果或用户体验的证明。

普通食品不能宣称保健功能，也不能涉及疾病预防、治疗功效。因此，审核应同时看文字、画面、声音及前后顺序，不能只检查是否出现某个敏感词。来源：[市场监管总局相关提示](https://www.samr.gov.cn/xw/sj/art/2025/art_e27f6eaa4c074317b256275698ba28d2.html)。

## 直观层的真实使用体验

新品尚未形成用户反馈时，直观层可以暂时为空。上市前完成品牌表达，不等于已经拥有真实口碑。

首批试饮和销售开始后，优先积累家长能够直接观察、描述和复核的体验：

包装是否方便开启、收纳和取用。

按指定方法冲调时的实际过程与状态。

家长对口味的描述，以及孩子实际接受或不接受的情况。

使用中遇到的问题、客服处理及后续反馈。

这些内容的价值在于帮助其他家庭理解真实使用体验，不把个别家庭的感受扩展为普遍效果。即使家长主动提到身高、少生病或学习变化，也不能直接选作本产品的功效证明。

每份可使用的反馈保留产品版本、体验时间、原始素材和授权范围；标清是购买用户、赠样试饮还是付费合作。不预设好评答案，不以好评作为获得样品的条件，不通过剪辑改变原意。内部同时保留负面与中性反馈，用于改进产品和表达。

涉及儿童画面时，优先采用产品、成人操作和不暴露身份的镜头；可识别儿童信息的采集与公开使用，应取得相应监护人授权。儿童出镜也不能直接等同于可用于广告推荐或证明，尤其不得利用不满十周岁的未成年人作为广告代言人。来源：[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)、[广告法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_5474cf75173c45d6a0379730fb4e8d97.html)。

品牌自行拍摄的生活短片，统一称为“品牌场景演绎”并明确标识，归入主观素材库；真实产品的冲调操作可作为产品演示，但不能伪装成消费者自发推荐。

AIGC用于分镜、场景构思、版式及内容适配，不生成假评价、假晒娃、假试饮记录，也不虚构生产现场、资质或检测证据。使用AI制作的品牌画面如实标明其性质。

## 素材管理与直播内容运营

建立事实、品牌表达、真实体验三个素材库。单项素材明确所属类别、产品版本、依据或授权、可使用范围及更新时间；成片可以跨层组合，但仍能追溯到原始素材。

执行上，内容随证据成熟而增加：

| 阶段 | 重点工作 | 可形成的内容 |
| :-: | :-: | :-: |
| 配方与标签确认前 | 建事实卡模板、整理家长问题、完成场景构思和视觉方向 | 已核实的品牌资料、一般性选购知识、明确标识的概念演绎 |
| 配方与样品确认后 | 完成三条线事实卡、差异说明和冲调演示 | 产品信息、直播讲解底稿、商品详情和客服答复 |
| 首批真实体验后 | 收集、核实并取得反馈使用授权 | 真实使用片段、体验答疑及问题改进记录 |
| 持续销售阶段 | 将咨询、退款原因和使用反馈回填内容库 | 更新后的事实说明、场景内容与真实体验素材 |

一场直播可根据家长当时的问题调用不同内容：询问成分时展示事实卡，不知道怎样选择时解释产品差异，对实际使用有顾虑时展示真实操作与经授权的反馈。没有真实反馈时，就用明确标识的产品演示回答能回答的问题。

这使主播、短视频、商品详情和客服使用同一套产品依据，同时保留各自适合的表达方式。

## 传播复盘与购买顾虑诊断

三层框架也用于发现传播缺口，但不把所有未成交都归因于内容不足。

| 家长表现或反馈 | 优先核查的问题 | 内容上的应对 |
| :-: | :-: | :-: |
| 反复问厂家、授权、配料和含量 | 事实是否清楚，来源是否可信 | 补充事实卡、来源说明和标签展示 |
| 了解成分后仍不知道为什么选、怎样喝 | 产品差异和使用价值是否讲明白 | 补充选择说明、生活场景与使用演示 |
| 担心口味、冲调和实际接受程度 | 体验信息是否不足 | 补充真实演示与经授权的家长反馈 |
| 已理解产品却仍不购买，或购买后退款 | 价格、规格、口味、服务或产品本身是否不合适 | 回到选品、定价和交付调整，不能仅靠追加传播解决 |

复盘时结合咨询原话、点击与支付、退款原因以及成熟订单贡献判断，不从单一的停留或点赞推断消费者心理。比较素材效果时，尽量保持人群、价格和投放条件可比，逐项验证。

内容的经营目标，是让家长更准确地理解产品、减少错误预期，并形成有质量的成交。播放量提高而退款同步上升，不能认定为传播成功。

## 事实内容与搜索及AI检索

事实卡除图片版外，还应保留结构清楚的文字版，统一产品名称、版本、规格、含量单位和更新时间，并链接至可核对的公开资料。这样既方便家长搜索，也为搜索引擎和AI系统理解产品提供基础。

本案将此作为GEO的内容准备，不预先承诺收录、推荐或引用效果。以Google公开说明为例，其AI搜索功能仍依赖可访问、可索引的内容和既有搜索基础，并不保证符合条件的页面一定展示；其他平台需分别验证。来源：[Google搜索中心说明](https://developers.google.com/search/docs/appearance/ai-features?hl=zh-cn)。

品牌传播由此形成持续更新的关系：事实确定能够表达什么，品牌说明为什么值得选择，真实体验检验表达是否准确。新品阶段先把能够证明的内容讲清楚，再用实际使用积累口碑。

# 基于消费者决策树的 GEO 与产品知识库建设

上一部分解决了“品牌应该准备什么内容”，本部分进一步解决“这些内容在消费者什么时候需要、通过什么入口被找到、怎样保持准确”。

本案以消费者决策树组织产品知识，将事实卡、场景内容和真实反馈连接起来，同时服务直播、客服、商品详情、搜索及AI问答。GEO，即生成式引擎优化，在本项目中的任务，是提高产品信息被发现、正确理解和准确引用的可能性。

以家长的问题组织知识，以可核对的证据支撑答案，以实际反馈修正内容。

新品阶段先建立准确的信息基础，再观察搜索与AI平台的实际反馈，不将内容发布量、品牌出现次数或单次推荐作为经营效果的替代指标。

## 消费者决策树决定内容应该解决什么问题

家长购买儿童奶粉，并不是从看到广告到下单的一条直线。有人先核查品牌，有人先看成分和价格，也有人因孩子不接受口味而重新选择。家庭成员还可能分别承担研究、付款、冲调、饮用和影响决策的角色。

本案不预先按性别或辈分分配这些角色，而是按实际任务准备内容。研究产品的人需要能够核对的依据，付款的人需要清楚的选择理由，冲调的人需要明确的方法，孩子的实际接受情况则影响持续使用。

决策树既要呈现继续购买的条件，也要允许退出、暂缓和重新选择。

| 决策节点 | 需要回答的问题 | 分支与处理方式 | 对应内容 |
| :-: | :-: | :-: | :-: |
| 需求识别 | 家庭希望解决什么实际饮食或使用问题 | 需求清楚则继续了解；不能由品牌内容直接诊断孩子缺什么 | 品类问答、日常场景说明 |
| 基础条件核查 | 年龄、配料、过敏提示及使用条件是否适合 | 不符合则停止推荐；信息不足先核查 | 产品身份、标签及相关提示 |
| 比较筛选 | 三款有什么区别，怎样比较成分、规格和价格 | 达到基本条件后再比较；否决项不能被包装或卖点抵消 | 事实卡、差异表、价格换算 |
| 家庭协商 | 能否向其他家庭成员说明选择理由 | 存在疑问则返回相应证据，不靠重复广告词说服 | 简明结论与完整依据 |
| 下单确认 | 买的是哪款、多少量、实付多少、有什么条件 | 规格、价格和服务条件清楚后，自主决定是否购买 | 商品信息、价格及售后说明 |
| 冲调使用 | 怎样冲、怎样存、孩子是否接受 | 遇到问题先提供服务；反复出现的问题回到产品与内容复核 | 冲调演示、使用问答、反馈记录 |
| 复购分享 | 是否愿意继续使用，什么体验值得分享 | 根据实际消耗和体验决定，不预设所有用户都会复购 | 补货说明、真实体验、问题改进记录 |

其中，比较筛选进一步区分三类条件：

门槛项是进入考虑范围的基本条件；否决项是一旦不满足，就应停止推荐或重新核查的条件；加分项是在基本条件满足后，能够提高偏好的特点，例如条装便利、视觉识别或口味体验。

传播应帮助家长识别这些差异，而不是用加分项掩盖否决项。

## 降低理解成本 同时保留核对入口

内容采用“简明结论＋事实依据＋适用条件”的双层表达。

第一层用熟悉的语言直接回答问题，便于家长快速理解和转述；第二层提供标签、含量单位、资料来源和必要限制，便于进一步核对。不能把所有问题都压成一句容易记住、却丢失条件的广告语。

“系统1、系统2”在本案中作为内容设计的参考，不把某个购买阶段固定归为直觉或理性。例如，价格判断既可能来自第一印象，也可能需要认真换算；家长看到配料表，也不代表已经充分理解。

具体执行遵循三点：

先降低阅读负担。 字号、对比、单位和结构统一，一屏突出一个问题。

再提供核对路径。 简短答案能够展开到完整资料，不隐藏影响选择的条件。

最后保留选择空间。 不通过焦虑、虚假稀缺或未经确认的默认选项促成购买。

单份价格可以辅助理解，但不得替代总价。按当前25g×28小包的规格，整盒价格除以28得到的是每小包价格；只有最终喝法明确一包对应一杯时，才能称为每杯价格。28包也不自动等于28天，应按最终建议用量说明。

首次开封、冲调和临近用完时，可以分别提供清晰的使用指引与补货信息。这是体验设计方向，不能据此预先认定复购率会提高。

## 从素材库升级为可追溯的产品知识库

素材库按图片、视频和文案存放，便于制作；知识库进一步记录“这段内容回答什么问题、依据是什么、适用于哪款产品、当前能否使用”。

知识库采用六类内容单元：

| 内容单元 | 核心任务 | 必要信息 |
| :-: | :-: | :-: |
| 实体卡 | 明确说的是哪个品牌、系列、产品或成分 | 标准名称、别名、规格、版本，以及品牌、生产企业、渠道方之间的真实关系 |
| 事实卡 | 保存可核对的产品信息 | 事实、单位、出处、适用范围、资料日期与核验状态 |
| 场景卡 | 解释产品怎样进入日常生活 | 时间、动作、使用问题、关联事实与表达边界 |
| 问答卡 | 回答家长的具体问题 | 简明结论、解释、适用条件、引用依据与无法确认的部分 |
| 体验卡 | 保存真实使用反馈 | 产品版本、原始素材、体验时间、商业关系、授权及核实情况 |
| 素材包 | 支持主播、达人及内容团队使用 | 图片、视频、文案、关联卡片编号、版本与使用范围 |

每条核心事实应能独立理解，同时保留必要上下文。例如成分含量不能只写一个数字，还应明确产品版本、每100g或每包的单位，以及该数字来自研发目标、配料添加记录还是成品资料。

状态管理分为两个维度：

事实状态： 待确认、已取得确认资料、已核验、需复核或已失效。

使用状态： 内部讨论、待审核、允许公开或停止使用。

工程师确认了配方参数，不等于相关宣传表达已经可以发布；内容通过表达审核，也不意味着其依据永远有效。产品版本或资料变化后，关联问答、图片和直播话术应同步复核。

每张卡再标注所属内容层、决策节点、服务角色、简答或详解形式、使用渠道和发布状态，用于查找决策链条中的内容缺口。

## 真实体验与商业合作分别记录

体验是否真实，与内容是否存在商业合作，是两个不同的问题。

赠样家长可以提供真实体验，但赠样关系应当说明；付费达人也可能真实使用产品，但其内容不能被包装成独立、自发的消费者评价。品牌自行拍摄的生活片则统一标为“品牌场景演绎”，沿用上一部分的分类。

体验卡同时记录两项属性：

证据属性： 原始使用记录、经核实的反馈、待核信息或品牌演绎。

商业关系： 自费购买、赠样试饮、付费合作或品牌制作。

由此既保留有价值的使用信息，也避免把广告内容汇总成虚假的自发口碑。多平台转载同一份体验，仍是一份原始来源，不能统计为多个独立家庭的反馈。

当真实体验与品牌主张发生冲突时，先标记相关主张“待复核”。例如“容易冲调”的表达遇到持续结块反馈，应核查水温、操作方法、产品批次及样品状态，再决定修改使用说明、品牌表达或产品本身。未经核实的反馈不能直接修改成分事实。

## 内部知识库与公开信息中心各司其职

内部知识库服务团队准确使用资料，公开信息中心服务消费者、合作方及外部检索。两者使用一致的已确认事实，但公开范围不同。

内部可以保留待定配方、报价、合作条款、测试过程和未经授权的原始反馈；对外只发布经核实、具备相应权限的内容。内部文件进入知识库，不等于允许对外公开。

网站可作为产品信息的统一发布入口和版本管理中心，但不将其称为唯一事实来源。事实依据仍来自标签、检测资料、生产记录、授权文件及其他适当的一手资料。

如果网站由高振运营，应如实说明渠道服务方身份；安琪纽特品牌、实际生产企业和渠道方分别建立清楚的关系，不因放在同一个网站，就形成品牌官方或生产主体的误认。

产品名称尚未确定时，可以先准备品类问答与内部实体结构。正式发布后，为产品保留稳定标识、名称变更记录和版本对应关系，降低旧名称、不同规格及不同配方被混淆的可能。

公众号、图文平台、短视频、直播和商品详情使用同一套核准事实，根据渠道调整表达形式。在平台允许的情况下提供原始资料入口；不能回链时，也应保持产品版本、单位和来源表述清楚。

多渠道发布的目的，是扩大有效信息的可达范围，而不是用重复发布制造“多方证实”。

## GEO的作用是提高可发现性与准确性

带检索能力的AI可以利用外部资料组织回答，但不同平台是否联网、检索哪些来源、怎样使用资料，存在差异。不能将所有AI回答都描述为固定的“检索—切片—交叉验证—生成”流程，也不能把内部知识库搭建等同于外部AI已经学习或收录了资料。[检索增强生成研究](https://arxiv.org/abs/2005.11401)

本案重点建设四类基础能力：

身份清楚。 让品牌、产品、规格和版本能够对应，减少同名、旧版和其他产品的信息混入。

事实完整。 数字与单位、来源、日期和适用条件一起出现，减少脱离上下文的引用。

内容可读取。 重要信息除图片外提供文字版，公开页面具备合理的访问与检索条件。

答案可追溯。 问答能回到依据；资料变更时，相关内容可以定位并更新。

客观事实、品牌主张和真实体验都可能被AI使用，但不存在“事实必被引用、场景必被提及、口碑必带来推荐”的固定对应关系。

以Google公开说明为例，其AI搜索功能仍以既有搜索基础为前提，符合要求也不保证展示。国内各平台的检索入口与来源偏好，应通过实际测试观察，不能把经验判断写成既定规则。[Google搜索中心说明](https://developers.google.com/search/docs/appearance/ai-features?hl=zh-cn)

## 用决策节点缺口指导内容迭代

建立“决策节点×客观、主观、直观”的内容矩阵，不要求每个节点机械地配齐三种素材，而是检查关键问题有没有适当的答案。

例如，适用年龄和过敏提示依赖明确事实，不能用家长好评补足；条装是否方便使用可以结合品牌演示和真实反馈，但不能由画面推出营养效果。

持续迭代采用以下顺序：

观察问题 → 判断可能障碍 → 补充或修正内容 → 比较反馈 → 保留有效版本。

这是经营反馈机制。可调整的是信息是否清楚、依据是否充分、产品是否方便理解；消费者是否购买以及外部AI是否引用，均不是能够直接控制的结果。

直播咨询、客服记录和退款原因用于发现问题；内容对照测试用于检验解释是否改善理解；成熟订单贡献用于判断成交质量。观察周期应考虑退款和实际使用的滞后，避免根据一次推荐、一天转化或少量好评频繁改动事实内容。

## 新品阶段的实施与评价

第一阶段先建立品类层的10个核心问答，覆盖类别理解、配料比较、年龄与相关提示、规格、价格换算、冲调和储存，并完成三款产品的内部实体结构。未确认的品牌关系、配方和用法不先行填充。

第二阶段在品名、配方、标签及相关授权确认后，形成产品实体卡、事实卡和差异问答，供直播、客服和商品详情统一使用；具备公开条件的内容再进入外部渠道。

第三阶段从首批真实体验积累反馈，按证据属性与商业关系分别记录，将高频问题回填知识库。

第四阶段开展AI检索基线与复测。可先选择豆包、DeepSeek、Kimi，以固定的10个问题形成每轮30个基础回答样本；记录测试日期、可见版本、联网设置、原始问题、回答和引用来源，必要时重复测试观察波动。该数量是测试设计，不是已完成结果。

测试问题分成两组：一组不预先提品牌，观察品类问答中的自然发现；另一组明确产品名称，检查身份、规格、含量和使用说明是否准确。两组结果分别报告。

| 评价层面 | 观察内容 | 能够说明什么 |
| :-: | :-: | :-: |
| 知识准备 | 关键决策节点是否有答案，依据是否有效 | 内容是否具备支持决策的基础 |
| 信息可达 | 目标平台能否读取或检索到公开资料 | 资料能否进入该平台的信息获取范围 |
| 回答准确 | 品牌、规格、含量单位及适用条件是否正确 | AI是否正确表达产品事实 |
| 引用质量 | 引用是否实际支持结论，是否混用其他产品 | 回答能否回到恰当证据 |
| 品牌呈现 | 是否提及、引用或推荐，发生在哪类问题中 | 品牌在特定测试条件下的呈现情况 |
| 经营反馈 | 可追踪访问、咨询、成交及退款后贡献 | 是否形成可观察的业务价值 |

被提及不等于被引用，被引用不等于被推荐，被推荐也不等于成交。只有取得相应访问、订单及归因依据后，才将结果纳入经营评价；无法归因的部分保留为未知。

本阶段形成的是一套能够逐步完善的产品知识与内容机制。实际建设、公开分发和平台测试按后续确定的范围推进，GEO效果以测试和经营记录持续验证。
